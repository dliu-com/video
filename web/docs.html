How it works

video.dliu.com hosts videos that anyone can watch and that other dliu.com sites can embed. There are no servers: files sit in S3, CloudFront delivers them, and one small Lambda function runs only when the owner signs in or changes a video.

Running costs

Everything is billed per use. With nobody watching, the only charge is storing the videos in S3.

Security

Anyone can watch; only the owner, signed in with Microsoft, can upload, edit or delete.
